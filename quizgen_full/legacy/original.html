1. Context-Based Grounding

To eliminate hallucinated questions, QuizGen injects extracted notes directly into the system prompt as reference context. The prompt explicitly instructs Gemini to strictly derive factual questions and answers from the context.

2. Structured JSON Output

QuizGen requires the LLM to output a strictly compliant JSON array containing objects with fields: question, options, answer, explanation, and topic.

3. Programmatic Evaluation

Evaluation does not rely on costly or non-deterministic LLM calls during submission. Objective answers are evaluated instantly on the client side using exact or normalized string comparison algorithms.

4. Personalized Weak Topic Practice

Each question carries a topic attribute. When a student answers incorrectly, the topic is tagged as a weak area. Students can click "Practice Weak Topics Only" to trigger a prompt focused specifically on those sub-domains.

Gemini API Settings

You can enter your standard Gemini API key below to enable real-time quiz generation using gemini-3-flash-preview. If left empty, QuizGen uses built-in seamless generation or runtime default key.
